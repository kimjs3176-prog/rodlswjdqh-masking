# PDF 개인정보 마스킹

PDF 문서에서 개인정보를 자동으로 찾아 가려 주는 **로컬 프로그램**입니다.
모든 처리는 내 컴퓨터 안에서만 이루어지며, 문서가 인터넷으로 전송되지 않습니다.

## 특징

- **복구 불가능한 마스킹** — 검은 상자만 덧씌우는 것이 아니라 해당 글자를 PDF 에서 실제로 삭제합니다. 복사·검색으로 되살릴 수 없습니다.
- **원본 보존** — 원본은 그대로 두고 `파일명_마스킹.pdf` 를 새로 만듭니다.
- **자동 재검사** — 저장한 결과를 다시 열어 남은 개인정보가 없는지 확인합니다.
- **미리 검사** — 파일을 바꾸지 않고 몇 건이 탐지되는지 먼저 볼 수 있습니다.
- 여러 파일·폴더 일괄 처리, 문서 속성(작성자 등) 삭제

## 탐지 항목

| 항목 | 예시 | "일부만 가리기" 결과 |
|---|---|---|
| 주민등록번호·외국인등록번호 | 900101-1234567 | 900101-■■■■■■■ |
| 휴대전화번호 | 010-1234-5678 | 010-■■■■-5678 |
| 일반전화번호 | 02-123-4567 | 02-■■■-4567 |
| 이메일 주소 | hong@example.com | ■■■■@example.com |
| 신용카드번호 | 1234-5678-9012-3456 | 1234-■■■■-■■■■-3456 |
| 운전면허번호 | 11-23-123456-78 | 11-23-■■■■■■-78 |
| 여권번호 | M12345678 | 전체 |
| 계좌번호 | 110-123-456789 | 전체 |
| 사용자 지정 단어 | 이름, 주소 등 직접 입력 | 전체 |

## 사용 방법 (Windows)

1. [파이썬](https://www.python.org/downloads/)을 설치합니다. 설치 화면에서 **Add python.exe to PATH** 를 체크하세요.
2. 이 저장소를 내려받아(Code → Download ZIP) 압축을 풉니다.
3. `실행.bat` 을 더블클릭합니다. 처음 한 번만 구성 요소를 설치하며(인터넷 필요), 이후에는 인터넷 없이 동작합니다.
4. 창에서 PDF 추가 → 가릴 항목 선택 → **마스킹 실행**.

## 명령줄 사용

```bash
pip install -r requirements.txt
```

```bash
python -m pdf_masker 문서.pdf
```

| 옵션 | 설명 |
|---|---|
| `-o 폴더` | 저장 폴더 지정 |
| `-k rrn,mobile` | 특정 항목만 탐지 (`rrn, mobile, phone, email, card, driver, passport, account`) |
| `-w 홍길동` | 추가로 가릴 단어 (여러 번 지정 가능) |
| `-r 정규식` | 추가로 가릴 정규식 |
| `--partial` | 일부만 가리기 |
| `--dry-run` | 파일을 만들지 않고 탐지 결과만 출력 |
| `--password 암호` | 암호가 걸린 PDF |
| `--keep-metadata` | 문서 속성을 지우지 않음 |

인자 없이 `python -m pdf_masker` 를 실행하면 창이 열립니다. 폴더를 지정하면 그 안의 PDF 를 모두 처리합니다.

## 주의 사항

- **스캔한 PDF(이미지)는 자동 탐지되지 않습니다.** 글자 정보가 없는 쪽은 결과에 경고로 표시되니 직접 확인하세요.
- 이름·주소처럼 형식이 정해지지 않은 정보는 "추가로 가릴 단어"에 직접 입력해야 합니다.
- 줄이 바뀌면서 끊긴 번호 등은 놓칠 수 있습니다. **자동 탐지는 완벽하지 않으므로 배포 전 결과 파일을 반드시 눈으로 확인하세요.**
