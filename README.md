# PDF·엑셀 개인정보 마스킹

PDF 문서와 엑셀 파일(.xlsx, .xlsm)에서 개인정보를 자동으로 찾아 가려 주는 **로컬 프로그램**입니다.
모든 처리는 내 컴퓨터 안에서만 이루어지며, 문서가 인터넷으로 전송되지 않습니다.

## 특징

- **복구 불가능한 마스킹** — 검은 상자만 덧씌우는 것이 아니라 해당 글자를 PDF 에서 실제로 삭제합니다. 복사·검색으로 되살릴 수 없습니다.
- **원본 보존** — 원본은 그대로 두고 `파일명_마스킹.pdf`(엑셀은 `파일명_마스킹.xlsx`)를 새로 만듭니다.
- **스캔 문서 지원** — 글자 정보가 없는 스캔(이미지) 쪽은 글자 인식(OCR, 한글·영문)으로 찾아 그림의 해당 부분을 지웁니다. 별도 프로그램 설치가 필요 없고 인터넷 없이 동작합니다.
- **엑셀 지원** — 모든 시트(숨김 포함)의 셀, 메모, 머리글·바닥글에서 개인정보 글자를 `*` 로 바꿉니다. 숫자로 저장된 주민등록번호·전화번호도 찾습니다.
- **자동 재검사** — 저장한 결과를 다시 열어 남은 개인정보가 없는지 확인합니다.
- **끌어다 놓기** — 파일이나 폴더를 창에 끌어다 놓으면 바로 추가됩니다.
- **미리 검사** — 파일을 바꾸지 않고 몇 건이 탐지되는지 먼저 볼 수 있습니다.
- 여러 파일·폴더 일괄 처리, 문서 속성(작성자 등) 삭제

| 항목 | 예시 | "일부만 가리기" 결과 |

| 일반전화번호 | 02-123-4567 | 02-■■■-4567 |
| 이메일 주소 | hong@example.com | ■■■■@example.com |
| 신용카드번호 | 1234-5678-9012-3456 | 1234-■■■■-■■■■-3456 |

### 가리지 않는 번호

개인정보와 모양이 비슷하지만 개인정보가 아닌 번호는 가리지 않습니다.

- 특허·실용신안·디자인·상표의 출원·공개·등록번호 (예: `10-2023-0012345`, `1020230012345`, `10-1234567-0000`)
- "출원번호", "공개번호", "특허번호", "Application No." 등의 이름표 바로 뒤에 오는 번호
- 사업자등록번호 형식 (`123-45-67890`)

이런 번호도 가리고 싶으면 "추가로 가릴 단어"에 직접 입력하세요.

## 사용 방법 (Windows)

### exe 로 실행 (파이썬 설치 불필요)

1. [Releases](https://github.com/kimjs3176-prog/rodlswjdqh-masking/releases/latest) 에서 `PDF-Masker.exe` 를 내려받습니다.
2. 더블클릭합니다. 설치 과정이 없고 인터넷 없이 동작합니다.
3. 창에서 PDF·엑셀 파일 추가 → 가릴 항목 선택 → **마스킹 실행**.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요(서명되지 않은 프로그램이라 뜨는 안내입니다).
첫 화면이 뜨기까지 몇 초 걸릴 수 있습니다.

### 파이썬으로 실행

1. [파이썬](https://www.python.org/downloads/)을 설치합니다. 설치 화면에서 **Add python.exe to PATH** 를 체크하세요.
2. 이 저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `실행.bat` 을 더블클릭합니다.

## 명령줄 사용

```bash
pip install -r requirements.txt
```

```bash
python -m pdf_masker 문서.pdf
```

| 옵션 | 설명 |
|---|---|
| `-o 폴더` | 저장 폴더 지정 |
| `-k rrn,mobile` | 특정 항목만 탐지 (`rrn, mobile, phone, email, card, driver, passport, account`) |
| `-w 홍길동` | 추가로 가릴 단어 (여러 번 지정 가능) |
| `-r 정규식` | 추가로 가릴 정규식 |
| `--partial` | 일부만 가리기 |
| `--dry-run` | 파일을 만들지 않고 탐지 결과만 출력 |
| `--password 암호` | 암호가 걸린 PDF |
| `--keep-metadata` | 문서 속성을 지우지 않음 |
| `--no-ocr` | 스캔 쪽의 글자 인식(OCR)을 하지 않음 |

인자 없이 `python -m pdf_masker` 를 실행하면 창이 열립니다. 폴더를 지정하면 그 안의 PDF 를 모두 처리합니다.

## 주의 사항

- **엑셀은 글자를 `*` 로 바꿉니다** (예: `900101-*******`). 저장 과정에서 도형·글상자와 셀 안의 부분 서식(일부 글자만 굵게 등)은 사라질 수 있고, 시트에 들어 있는 그림과 시트 이름은 검사·수정하지 않습니다(결과에 안내가 표시됩니다). 옛 형식(.xls)과 암호가 걸린 파일은 지원하지 않습니다.

- **스캔한 PDF 는 글자 인식(OCR) 결과에 의존합니다.** 흐리거나 기울어진 스캔, 손글씨, 도장에 겹친 글자는 인식하지 못해 빠질 수 있습니다. OCR 로 처리한 쪽은 결과에 표시되니 꼭 직접 확인하세요.
- 이름·주소처럼 형식이 정해지지 않은 정보는 "추가로 가릴 단어"에 직접 입력해야 합니다.
- 줄이 바뀌면서 끊긴 번호 등은 놓칠 수 있습니다. **자동 탐지는 완벽하지 않으므로 배포 전 결과 파일을 반드시 눈으로 확인하세요.**

### 새 버전 내기

`pdf_masker/__init__.py` 의 `__version__` 숫자를 올려 `main` 에 반영하면, GitHub Actions 가 exe 를 빌드해 `v버전` 릴리스를 자동으로 만듭니다. 버전이 그대로면 릴리스는 바뀌지 않습니다.

OCR 은 PyMuPDF 에 내장된 Tesseract 엔진과 `pdf_masker/tessdata` 의 언어 데이터([tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), Apache-2.0)를 사용합니다.

PDF 처리는 [PyMuPDF](https://pymupdf.readthedocs.io/)(AGPL-3.0)를 사용합니다.
